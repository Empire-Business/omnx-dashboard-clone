# Russell Brunson — Rodada 2

Hormozi, você acertou na veia quando falou em separar o lugar da decisão do lugar da execução. Isso é puro funil de navegação: etapa de cima é estratégica, etapa de baixo é operacional. Mas eu discordo de uma coisa — você ainda está pensando em "velocidade" como se o problema fosse só tempo. Não é. O problema é **aquecimento de contexto**. Quando o SDR entra no dashboard, ele precisa saber imediatamente: "estou no lugar certo para a ação que eu quero fazer?". Se configuração global está escondida dentro de um app, o cérebro dele queima energia tentando se localizar. E energia mental gasta em navegação é energia que não vira conversão. Então sim, separe global de contextual — mas faça isso com uma hierarquia visual clara, não só com um botão novo.

Sandro, você bateu forte dizendo que dashboard é terreno, não casa. Concordo com a metáfora, mas discordo da conclusão. Terreno sem acesso organizado é só lote baldio. Você precisa de um **funil de entrada**: o usuário não chega no topo do dashboard pronto para governar tudo. Ele chega querendo fazer uma ligação, mandar uma mensagem, ver um lead. Depois, quando cresce, ele sobe na value ladder da própria ferramenta e passa a precisar de configurações globais. Então o espaço de administração não pode ser só uma "regra de ouro" técnica — ele precisa ser descoberto organicamente quando o usuário amadurece. Ícone de engrenagem no header é o mínimo; o ideal é a plataforma educar o usuário sobre onde mora cada tipo de decisão.

Marcel, você trouxe a palavra certa: governança. Mas governança sem funil vira burocracia. O que falta no seu diagnóstico é a sequência de adoção. Não adianta criar um espaço de admin global bonito se o time continua encontrando atalhos antigos, abrindo configuração dentro do app porque é o caminho que o músculo dele memorizou. A refatoração precisa incluir **redirecionamentos inteligentes**: quando alguém clicar em "configurações de apps" dentro de um módulo, ele não deve quebrar — deve ser levado para o lugar certo, com uma mensagem clara: "configurações globais agora vivem aqui". Isso é transição de funil, não só reorganização de menu.

Minha prioridade continua a mesma, mas agora com uma camada a mais: crie um **Funil de Navegação Empire**. Topo: conta e administração global (apps, usuários, permissões, configurações de tenant). Meio: seletor de apps + AppHub como página de entrada contextual. Fundo: dentro de cada app, só configurações que pertencem àquele contexto. E teste não só perguntando "achou?", mas simulando a jornada real: novo SDR no primeiro dia, closer experiente, gerente de operações. Cada um deve saber, em três segundos, em qual etapa do funil ele está.
