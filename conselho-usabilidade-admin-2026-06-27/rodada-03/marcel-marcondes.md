# Rodada 3 — Marcel Marcondes

Grant me convenceu em uma coisa: esperar dados para agir aqui é luxo que o produto não tem. O usuário gritou. Isso é dado qualitativo suficiente para priorizar. O que preciso preservar é que a solução implementada tenha métricas de sucesso definidas antes — não para atrasar, mas para saber quando parar de iterar. "Tempo do admin até primeira ação em /admin/apps menor que 30 segundos" é a métrica. Simples, mensurável, relevante.

O que não abro mão: hierarquia visual clara entre papéis. O sistema precisa comunicar ao admin que ele tem poderes que outros não têm — não como ego, mas como clareza funcional. Um SDR que vê opções de admin no sistema se pergunta "o que é isso?" e o admin que não vê opções de admin se pergunta "onde está isso?" Os dois problemas são evitáveis com visibilidade condicional bem implementada.

Cedo no tempo: não precisamos de 2 semanas de planejamento. A solução mínima viável é: seção "Workspace" na sidebar inferior visível só para admins, com 2 links diretos (Apps e Pessoas), mais CTA no AppHub para admins sem configuração completa. Isso implementa em 1 dia, mede em 1 semana. Vamos fazer.
