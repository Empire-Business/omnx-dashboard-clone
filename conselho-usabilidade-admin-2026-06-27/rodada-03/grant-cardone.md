# Rodada 3 — Grant Cardone

Sandro estava certo sobre a cor diferenciada — eu estava sendo impaciente. Cor diferenciada no header cria problema de manutenção e divide o sistema visual. Visibilidade condicional faz o mesmo trabalho sem o custo. Aceito. O que importa é que o admin VÊ a entrada, não que ela seja colorida de laranja.

O que não abro mão: o admin precisa chegar ao controle de apps em 1 clique a partir de qualquer tela do sistema. Não 2, não 3. Um. Isso significa entrada no header ou na sidebar inferior — sempre visível, nunca em submenu aninhado. Se o admin está em /pre-vendas/discagem e precisa ativar um app, ele não pode ter que ir ao AppHub primeiro. A entrada de admin é global ou não é.

Cedo no checklist de onboarding: aceito que viva no AppHub e não como popup no header. Russell estava certo que o momento de ativação é quando o admin vê o hub pela primeira vez — não quando está no meio de uma tarefa operacional. O checklist no AppHub para workspaces incompletos + entrada global de 1 clique na sidebar para todos os outros momentos. Esse é o plano que fecha.
