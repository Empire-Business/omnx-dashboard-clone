# Rodada 3 — Alex Hormozi

Gary está certo em uma coisa que eu subestimei: o usuário novo que nunca viu o painel de admin não sabe o que está perdendo. Você não pode converter alguém que não chegou ao momento de ativação. O AppHub como ponto de entrada para o primeiro setup não é funil — é matemática básica de retenção. Aceito.

O que não abro mão: sidebar inferior com entradas diretas para admins. Não dropdown, não modal, não menu aninhado. Link. Um clique. É a diferença entre o admin que configura o workspace diariamente e o que entra uma vez por mês perdido. Essa distinção importa porque o controle de apps é um ativo de retenção — quanto mais o admin usa, mais ele fica. Esconder esse ativo é deixar dinheiro na mesa.

Se tenho que ceder uma coisa: aceito que o checklist de onboarding do Grant viva no AppHub e não na sidebar. O AppHub é o momento de ativação, a sidebar é a operação contínua. São dois contextos. Um plano que separa isso sem duplicar complexidade tem meu voto.
