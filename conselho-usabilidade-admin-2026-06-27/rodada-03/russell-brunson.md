# Rodada 3 — Russell Brunson

Vou ser honesto: Sandro me fez pensar. A diferença entre tratar o admin como lead no funil e tratar como profissional autônomo é real. Se o admin precisa de uma sequência guiada para ativar apps do próprio workspace, a gente criou produto confuso — não produto que precisa de onboarding. Reconheço parcialmente o argumento dele.

O que não abro mão: existe um momento de primeiro acesso que precisa ser tratado com cuidado. O admin que abre o sistema pela primeira vez e não sabe por onde começar não vai explorar — vai fechar. Precisamos de um estado inicial claro no AppHub que diga "configure seu workspace aqui" com um CTA visível. Isso não é tratar admin como lead. É eliminar fricção no momento mais crítico.

Cedo nisso: aceito que depois da primeira configuração, o sistema não precisa mais de guia. A sidebar inferior de Hormozi resolve o dia-a-dia. O meu onboarding é para o dia 1. O dela é para o dia 100. São complementares, não concorrentes. Podemos ter os dois.
