# Rodada 3 — Gary Vaynerchuk

Hormozi tinha razão no que eu não queria admitir: eu estava pensando demais no usuário novo e de menos no admin que usa o sistema todo dia. Os dois existem. O admin que está no dia 100 e precisa entrar em /admin/apps rápido não vai querer ver o AppHub toda vez. A sidebar inferior como atalho para power users faz sentido total.

O que não abro mão: a entrada no AppHub precisa existir com clareza visual. Quando o admin loga pela primeira vez e vê o hub de apps, tem que ter algo que diga "é aqui que você gerencia seu workspace" — não como tutorial, mas como sinalização honesta. Um produto que não se explica para o usuário novo está apostando em documentação que ninguém lê.

Cedo em cor diferenciada. Grant estava com pressa. Cor diferenciada no header para admin cria dois sistemas visuais que precisam ser mantidos. Visibilidade condicional — o item aparece ou não aparece dependendo do papel — resolve o problema sem criar poluição. Isso eu aceito.
