# Russell Brunson — Rodada 2: Embates

Alex, você está pensando pequeno aqui — e isso raramente acontece, então preste atenção. A sidebar inferior resolve o problema para o admin que já conhece o sistema. Mas o admin que acabou de assinar o plano, entrou no sistema pela primeira vez e está confuso — esse cara nunca vai olhar para o canto inferior da sidebar. Ele precisa de um funil. Não o funil de vendas que eu defendo — um funil de ativação. AppHub → card "Configurar seu workspace" em destaque → tela de admin → apps ativados. Essa sequência tem que existir no primeiro acesso e nunca mais aparecer depois. É o hook de ativação, e sem ele o produto nunca decola de verdade.

Gary, concordo que empatia é o ponto de partida. Mas "link na sidebar" resolve sintoma, não causa. A causa é que o produto não guia o admin pelo momento mais importante da jornada dele: a configuração inicial do workspace. Pense assim: se o admin não ativa os apps certos no primeiro dia, ele nunca experimenta o produto completo. Ele vai usar metade do sistema, não ter o resultado esperado, e vai embora em 60 dias achando que o produto é fraco. O produto não é fraco — o onboarding é.

Sandro, sua distinção entre Operação e Governança é elegante, mas você está separando coisas que o usuário não percebe como separadas. O admin que está gerenciando SDRs e também precisa ativar um novo app não quer mudar de "modo mental" para fazer isso. Ele quer resolver os dois no menor número de cliques possível. A entrada de admin precisa ser acessível de qualquer ponto, sim — mas o fluxo de configuração inicial ainda precisa ser guiado e linear, porque admin confuso não é admin soberano.
